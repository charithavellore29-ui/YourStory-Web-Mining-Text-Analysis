
# YourStory Web Mining & Text Analysis

## Project Overview
A web mining and text analysis project based on content collected from YourStory.com.

## Project Objective
To collect and analyse website text data to identify patterns, frequently occurring terms, themes and insights from published content.

## Tools & Technologies
- Python
- Microsoft Excel
- Voyant Tools
- Web Scraping

## Methodology
- Website content collection
- Text data extraction
- Data cleaning and preparation
- Text mining and analysis
- Visualisation and interpretation of findings


## Project Files

- `YourStory_Web_Mining_Report.pdf` — Project report documenting the web mining and text analysis work.
- `yourstory-com-2026-10-26.xlsx` — Collected YourStory.com website data in Excel format.

## Project Focus

- Website data collection
- Text data preparation
- Web mining
- Text analysis
- Identification of content patterns and themes
